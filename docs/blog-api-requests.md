# 블로그에 요청할 변경 목록

블로그 repo(`playground`)는 이 프로젝트에서 수정하지 않는다. 아래 항목은 블로그 쪽 별도 이슈/PR로 처리한다.

| # | 변경 | 필요한 이유 | 선행 대상 |
|---|---|---|---|
| 1 | 로그인 후 토큰 리디렉션 페이지 (예: `/admin-login?redirect=<관리앱 콜백>`) | 관리 앱이 쿠키 없이 JWT를 받기 위함. ADMIN 세션이면 `redirect#token=...`으로 이동 | 로그인 연동 |
| 2 | 운영 Vercel에 `ADMIN_APP_ORIGIN` 환경변수 설정 | 현재 미설정이라 CORS가 전부 거부됨 | 로그인 연동 |
| 3 | 관리자용 글 단건 조회 `GET /api/admin/posts/[type]/[slug]` | 임시저장 글 조회 + 조회수 증가 없이 본문·태그 반환 | 글 수정 화면 |
| 4 | 목록 정렬 파라미터 (`sort=viewCount`, `order=desc`) | 조회수 현황 화면 | 조회수 화면 |
| 5 | 조회수 통계 API (합계, 상위 N개 글) | 조회수 현황 요약 | 조회수 화면 |

## 구현 시 주의
- 1번의 `redirect` 대상은 `ADMIN_APP_ORIGIN`과 일치하는지 엄격히 검증한다(오픈 리디렉트 방지).
- 토큰은 쿼리스트링이 아닌 해시 프래그먼트로 전달한다(서버 로그·Referer 노출 방지).

## 범위 밖 (후속 이슈)
- `SiteVisit` 기록 코드와 방문 통계 집계 API (봇 필터, 개인정보 정책 포함)
